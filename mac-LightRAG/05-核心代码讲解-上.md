**合并算法详解**:

**实体合并**:
```
输入: 同名实体的多个记录
处理:
  1. 合并描述列表
  2. 描述去重（基于语义相似度）
  3. 合并来源文档列表
  4. 更新权重（出现次数累加）
输出: 合并后的单一实体
```

**关系合并**:
```
输入: 同对实体的多个关系记录
处理:
  1. 合并关键词列表（去重）
  2. 合并描述列表（去重）
  3. 合并来源文档列表
  4. 权重累加
输出: 合并后的单一关系
```

6. **流水线消息创建**: 创建 `PipelineIngressMessage`
7. **入队**: 发送消息到流水线队列

## 5.6 本章小结

本章对 LightRAG 的三个核心文件进行了深度走读：

1. **lightrag.py**: 系统主类，通过 Mixin 组合实现多功能，管理所有存储实例
2. **operate.py**: 知识图谱操作核心，包含实体/关系抽取、图谱合并、查询处理
3. **pipeline.py**: 文档入库流水线，三段式处理（解析-分析-抽取），并发控制

**核心设计特点**:
- **Mixin 组合**: 通过多继承实现代码复用
- **异步优先**: 全链路 AsyncIO
- **并发控制**: 信号量 + 优先级队列
- **错误隔离**: 文档级失败不影响其他文档
