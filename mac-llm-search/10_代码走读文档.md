## 10.1 Config 体系走读

### 10.1.1 从 YAML 到 Config 对象的完整路径

```
用户编写 YAML 文件
    ↓
llmsearch index create -c config.yaml
    ↓
cli.py: generate_index(config_file)
    ↓
config.py: get_config(path)
    ↓
yaml.safe_load(f) → Python 字典
    ↓
Config(**dict) → Pydantic 验证
    ↓
    ├── EmbeddingsConfig(**dict['embeddings'])
    │   ├── DocumentPathSettings(**doc_settings)
    │   │   ├── validate_path() → 检查路径存在
    │   │   └── validate_extension() → 检查扩展名
    │   └── EmbeddingModel(**embedding_model)
    ├── SemanticSearchConfig(**dict['semantic_search'])
    │   ├── HydeSettings(**hyde)
    │   ├── MultiQuerySettings(**multiquery)
    │   └── ConversrationHistorySettings(**history)
    └── LLMConfig(**dict['llm'])
        └── validate_params() → 动态验证模型参数
```

### 10.1.2 关键验证点

1. **路径验证**：`doc_path` 必须存在且是目录
2. **扩展名验证**：`additional_parser_settings` 的键必须是 md/pdf/docx/doc
3. **LLM 参数验证**：根据 `type` 动态选择配置类进行验证

### 10.1.3 配置分离设计

```python
# 文档配置（doc_config.yaml）
embeddings:
  document_settings:
    - doc_path: /path/to/docs
      scan_extensions: [md, pdf]
semantic_search:
  max_k: 10

# 模型配置（llm_config.yaml）
llm:
  type: openai
  params:
    model_kwargs:
      model_name: gpt-4o-mini

# 合并
config = get_doc_with_model_config(doc_config, llm_config)
```

## 10.2 索引生成走读

### 10.2.1 从 CLI 命令到 ChromaDB 写入的全链路

```
$ llmsearch index create -c config.yaml

cli.py: generate_index(config_file)
├── config = get_config(config_file)
├── set_cache_folder(str(config.cache_folder))
├── vs = VectorStoreChroma(persist_folder=..., config=config)
│   ├── self._embeddings = get_embedding_model(config.embeddings.embedding_model)
│   └── self.batch_size = 200
└── create_embeddings(config, vs)
    ├── splitter = DocumentSplitter(config)
    │   ├── self._splitter_conf = {md: ..., pdf: ..., docx: ...}
    │   └── self._fallback_splitter = UnstructuredSplitter().split_document
    ├── all_docs, hash_mappings, docid_mappings, labels = splitter.split()
    │   ├── for setting in document_settings:
    │   │   ├── for scan_extension in setting.scan_extensions:
    │   │   │   ├── for chunk_size in chunk_sizes:
    │   │   │   │   ├── paths = glob(**/*.ext)
    │   │   │   │   ├── splitter = _splitter_conf.get(ext, fallback)
    │   │   │   │   └── docs = splitter(path, max_size, ...)
    │   │   │   │       ├── markdown_splitter → 递归逻辑分片
    │   │   │   │       ├── PDFSplitter → MuPDF 文本分片
    │   │   │   │       └── docx_splitter → 递归分片
    │   │   └── all_docs.extend(docs)
    │   └── return all_docs, hash_mappings, docid_mappings, labels
    ├── vs.create_index_from_documents(all_docs)
    │   ├── shutil.rmtree(persist_folder)  # 清空旧数据
    │   └── for group in chunker(all_docs, size=200):
    │       ├── Chroma.from_documents(documents=group, ...)  # 首次
    │       └── vectordb.add_texts(texts=..., ids=..., metadatas=...)  # 后续
    ├── splade = SparseEmbeddingsSplade(config)
    │   ├── self.tokenizer = AutoTokenizer.from_pretrained(splade_model_id)
    │   └── self.model = AutoModelForMaskedLM.from_pretrained(splade_model_id)
    ├── splade.generate_embeddings_from_docs(docs=all_docs)
    │   ├── for chunk in split(docs, chunk_size=n_batch):
    │   │   ├── texts = [d.page_content for d in chunk]
    │   │   └── vecs.append(self._get_batch_embeddings(texts))
    │   │       ├── tokens = self.tokenizer(texts, ...)
    │   │       ├── output = self.model(**tokens)
    │   │       └── vecs = max(log(1 + ReLU(logits)) * mask, dim=1)
    │   └── persist_embeddings(vecs, metadatas, ids)
    │       ├── scipy.sparse.save_npz(fn_embeddings, csr_matrix)
    │       └── pickle.dump(ids, fp)
    ├── save_document_hashes(config, hash_mappings, docid_mappings)
    │   └── df.to_parquet(file_hashes_fn, compression='snappy')
    └── update_document_labels(config, labels)
```

**Document 对象**：

## 10.3 RAG 问答走读

### 10.3.1 从用户输入到 LLM 响应的全链路

```
用户输入: "什么是RAG"

api.py: llmsearch(question="什么是RAG", ...)
├── 检查 label 是否存在
└── get_and_parse_response(query="什么是RAG", ...)
    ├── 查询重写（如果启用历史）
    │   └── contextualize_query_with_history_chat(llm_bundle, user_question)
    │       └── history_contextualization_chain.invoke({chat_history, user_question})
    ├── 查询增强（三选一）
    │   ├── HyDE: hyde_chain.invoke(query) → 假设文档
    │   ├── MultiQuery: multiquery_chain.invoke({question, n_versions}) → 查询变体
    │   └── 无增强: queries = [query]
    ├── 检索
    │   └── get_relevant_documents(original_query, queries, ...)
    │       ├── for chunk_size in chunk_sizes:
    │       │   └── for query in queries:
    │       │       ├── sparse_retriever.query(search=query, n=max_k, ...)
    │       │       │   └── embeddings.dot(embed_query) / (l2_norm * l2_norm_query)
    │       │       ├── store.similarity_search_with_relevance_scores(query, k=max_k)
    │       │       └── all_doc_ids = set(sparse_ids).union(set(dense_ids))
    │       ├── rerank(reranker, original_query, all_relevant_docs)
    │       │   ├── scores = reranker.get_scores(query, docs)
    │       │   └── sorted(docs, key=lambda d: d.metadata['score'])
    │       └── 选择最佳 chunk_size 结果
    ├── 上下文窗口裁剪
    │   ├── 过滤 score < score_cutoff 的文档
    │   └── 累积到 max_char_size 为止
    ├── LLM 生成
    │   └── chain.invoke({context: most_relevant_docs, question: original_query})
    │       ├── prompt = prompt_template.format(context=..., question=...)
    │       └── llm.generate(prompt) → 答案文本
    ├── 构建响应
    │   └── ResponseModel(
    │       response=res,
    │       question=query,
    │       average_score=score,
    │       semantic_search=[SemanticSearchOutput(...)]
    │   )
    └── 持久化（如果启用）
        └── create_response(config, session, response)
            ├── get_or_store_config(config, session)
            ├── session.add(InteractionSourcesBridge(...))
            └── session.commit()
```

### 10.3.2 关键决策点

1. **查询增强选择**：HyDE 和 MultiQuery 互斥，优先 HyDE
2. **重排序分数**：Top-5 平均分作为整体质量分数
3. **上下文裁剪**：按字符数限制，不是文档数量
4. **响应链接处理**：路径替换 → Obsidian URI → 后缀追加

## 10.4 文档解析走读

### 10.4.1 Markdown 解析的详细执行路径

```
markdown_splitter(path, max_chunk_size=1024, ...)
├── 读取文件内容
├── if len(markdown) < max_chunk_size:
│   └── return [{"text": markdown, "metadata": {"heading": ""}}]
├── preprocess_markdown(markdown, settings)
│   ├── remove_images() → 正则移除 ![...](...)
│   ├── remove_extra_newlines() → \n{3,} → \n\n
│   └── find_metadata() → 提取 YAML front matter
├── chunks = markdown.split("```") → 按代码块分割
├── for i, chunk in enumerate(chunks):
│   ├── if i % 2 == 0:  # 非代码块
│   │   └── get_logical_blocks_recursively(chunk, max_size, [])
│   │       ├── for split_candidate in BLOCK_SPLIT_CANDIDATES:
│   │       │   └── re.split(split_candidate, chunk)
│   │       ├── if len(chunk) <= max_size:
│   │       │   └── all_sections.append(MarkdownChunk(string=chunk, level=level))
│   │       └── else:
│   │           └── get_logical_blocks_recursively(chunk, max_size, next_level)
│   └── else:  # 代码块
│       ├── 合并到前一个逻辑块（如果有空间）
│       ├── 物理分片（如果代码块太大）
│       └── 独立分片（如果无法合并）
└── postprocess_sections(sections, ...)
    ├── 移除空分片
    ├── 跳过第一个分片（如果配置 skip_first）
    ├── 合并小分片（如果配置 merge_sections）
    └── 添加元数据头部
        └── add_section_metadata(string, metadata)
            └── "Metadata applicable to...\n*****\n{text}\n*****"
```

### 10.4.2 PDF 解析的详细执行路径

```
PDFSplitter.split_document(path, max_size, ...)
├── doc = pymupdf.open(document_path)
├── for page in doc:
│   ├── blocks = page.get_text_blocks()
│   ├── filter_bboxes = table_bboxes[page.number] + image_bboxes[page.number]
│   ├── if filter_bboxes:
│   │   └── text = filter_blocks(blocks, filter_bboxes, page.number)
│   │       └── for block in blocks:
│   │           └── if not do_boxes_intersect(block.bbox, filter_bbox):
│   │               └── s += block[4]  # 保留不相交的文本
│   ├── else:
│   │   └── text = "".join([b[4] for b in blocks])
│   ├── if len(text) > max_size:
│   │   ├── splitter.split_text(text) → 分片
│   │   └── all_chunks.extend(chunks)
│   ├── elif len(current_text + text) >= max_size:
│   │   ├── all_chunks.append({"text": current_text, ...})
│   │   └── current_text = text
│   └── else:
│       └── current_text += text
└── return all_chunks
```

## 10.5 增量更新走读

### 10.5.1 Hash 对比到向量更新的全链路

```
$ llmsearch index update -c config.yaml

cli.py: udpate_index(config_file)
├── config = get_config(config_file)
├── vs = VectorStoreChroma(...)
└── update_embeddings(config, vs)
    ├── splitter = DocumentSplitter(config)
    ├── new_hashes_df = splitter.get_hashes()
    │   └── for setting in document_settings:
    │       └── for path in glob(**/*.ext):
    │           └── {"filename": str(path), "filehash": get_md5_hash(path)}
    ├── existing_fn_hash_mappings = pd.read_parquet(file_hashes_fn)
    ├── existing_docid_hash_mappings = pd.read_parquet(docid_hash_fn)
    ├── changed_or_new, changed, deleted = get_changed_or_new_files(new, existing)
    │   └── merged_df = new.merge(existing, on=[filehash, filename], how='outer', indicator=True)
    │       ├── changed_or_new = merged_df[merged_df['_merge'] == 'left_only']
    │       ├── changed = merged_df[duplicated_filename]
    │       └── deleted = merged_df[right_only & not in changed]
    ├── if no changes: return stats
    ├── splade = SparseEmbeddingsSplade(config)
    ├── splade.load()
    ├── # 处理变更文件
    │   ├── changed_doc_ids = existing_docid_hash[filehash.isin(changed.filehash)].docid
    │   ├── vs.delete_by_id(changed_doc_ids)
    │   ├── splade.delete_by_ids(changed_doc_ids)
    │   └── delete_mappings(existing_fn, existing_docid, changed)
    ├── # 处理删除文件
    │   ├── deleted_doc_ids = existing_docid_hash[filehash.isin(deleted.filehash)].docid
    │   ├── vs.delete_by_id(deleted_doc_ids)
    │   └── splade.delete_by_ids(deleted_doc_ids)
    ├── # 处理新增/修改文件
    │   ├── splitter.split(restrict_filenames=changed_or_new.filename)
    │   ├── vs.add_documents(new_docs)
    │   └── splade.add_embeddings(new_docs)
    └── save_document_hashes(config, updated_fn_mappings, updated_docid_mappings)
```
