## 11.1 环境准备

### 11.1.1 系统要求

| 组件 | 最低要求 | 推荐配置 |
|------|----------|----------|
| **操作系统** | Linux / macOS / Windows (WSL2) | Ubuntu 22.04 LTS |
| **Python** | 3.10+ | 3.11 |
| **内存** | 8 GB | 16 GB+ |
| **存储** | 10 GB 可用 | 50 GB+ SSD |
| **GPU** | 可选 | NVIDIA GPU with 8GB+ VRAM |

### 11.1.2 依赖安装

```bash
# 安装 Python 3.10+
sudo apt update
sudo apt install python3.11 python3.11-venv python3.11-dev

# 安装 NVIDIA 驱动（如果使用 GPU）
sudo apt install nvidia-driver-535
nvidia-smi  # 验证安装

# 安装 NVIDIA Container Toolkit（如果使用 Docker）
curl -s -L https://nvidia.github.io/nvidia-docker/gpgkey | sudo apt-key add -
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -s -L https://nvidia.github.io/nvidia-docker/$distribution/nvidia-docker.list | sudo tee /etc/apt/sources.list.d/nvidia-docker.list
sudo apt update
sudo apt install nvidia-container-toolkit
sudo systemctl restart docker
```

## 11.2 本地安装

### 11.2.1 方式一：使用 uv（推荐）

```bash
# 安装 uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# 克隆仓库
git clone https://github.com/snexus/llm-search.git
cd llm-search

# 创建虚拟环境并安装依赖
uv venv
source .venv/bin/activate
uv pip install -e ".[dev]"

# 验证安装
llmsearch --help
```

### 11.2.2 方式二：使用 pip

```bash
# 克隆仓库
git clone https://github.com/snexus/llm-search.git
cd llm-search

# 创建虚拟环境
python -m venv venv
source venv/bin/activate

# 安装依赖
pip install -e ".[dev]"

# 验证安装
llmsearch --help
```

### 11.2.3 方式三：使用 Docker

```bash
# 克隆仓库
git clone https://github.com/snexus/llm-search.git
cd llm-search

# 启动 Docker 容器
./run_docker.sh /path/to/storage

# 在容器内安装
cd /shared
pip install -e ".[dev]"
```


### 11.3.2 YAML 配置编写

#### 最小配置示例

```yaml
# config.yaml
cache_folder: ./cache

embeddings:
  embeddings_path: ./embeddings
  embedding_model:
    type: sentence_transformer
    model_name: 'Alibaba-NLP/gte-large-en-v1.5'
    additional_kwargs:
      trust_remote_code: true
  chunk_sizes:
    - 1024
  document_settings:
    - doc_path: ./docs
      scan_extensions:
        - md
        - pdf
      label: my_docs

semantic_search:
  search_type: similarity
  max_k: 10
  max_char_size: 8192

llm:
  type: openai
  params:
    prompt_template: |
      Context information is provided below.
      Given only the context, answer the question.
      ### Context:
      {context}
      ### Question: {question}
    model_kwargs:
      temperature: 0.0
      model_name: gpt-4o-mini
```

#### 完整配置示例

```yaml
# full_config.yaml
cache_folder: ./cache

embeddings:
  embeddings_path: ./embeddings
  embedding_model:
    type: instruct
    model_name: 'hkunlp/instructor-large'
  splade_config:
    n_batch: 5
  chunk_sizes:
    - 512
    - 1024
  document_settings:
    - doc_path: ./docs/obsidian
      exclude_paths:
        - ./docs/obsidian/templates
      scan_extensions:
        - md
        - pdf
      additional_parser_settings:
        md:
          skip_first: true
          remove_images: true
          merge_sections: false
      passage_prefix: "passage: "
      label: obsidian
    - doc_path: ./docs/papers
      scan_extensions:
        - pdf
      pdf_table_parser: gmft
      pdf_image_parser:
        image_parser: gemini-1.5-flash
      label: papers

semantic_search:
  search_type: similarity
  max_k: 15
  score_cutoff: 0.5
  max_char_size: 16384
  query_prefix: "query: "
  reranker:
    enabled: true
    model: bge
  hyde:
    enabled: false
  multiquery:
    enabled: false
  conversation_history_settings:
    enabled: true
    max_history_length: 3
    rewrite_query: true

persist_response_db_path: ./responses.db
```

### 11.3.3 配置参数速查表

| 参数路径 | 类型 | 默认值 | 说明 |
|----------|------|--------|------|
| `cache_folder` | Path | — | 模型缓存目录 |
| `embeddings.embedding_model.type` | str | instruct | 嵌入模型类型 |
| `embeddings.chunk_sizes` | List[int] | [1024] | 分片大小列表 |
| `embeddings.splade_config.n_batch` | int | 5 | SPLADE 批处理大小 |
| `semantic_search.max_k` | int | 15 | 最大检索文档数 |
| `semantic_search.max_char_size` | int | 16384 | 上下文窗口大小 |
| `semantic_search.reranker.model` | str | bge | 重排序模型 |
| `semantic_search.hyde.enabled` | bool | false | 启用 HyDE |
| `semantic_search.multiquery.enabled` | bool | false | 启用 MultiQuery |

## 11.4 CLI 使用

### 11.4.1 生成索引

```bash
# 基本用法
llmsearch index create -c config.yaml

# 输出示例
# 2024-01-01 12:00:00 | INFO | Loading doc config from a file: config.yaml
# 2024-01-01 12:00:01 | INFO | Scanning path for extension: md
# 2024-01-01 12:00:05 | INFO | Got 150 chunks for type: md
# 2024-01-01 12:00:10 | INFO | Generating and persisting the embeddings..
# 2024-01-01 12:00:30 | INFO | Generated embeddings. Persisting...
# 2024-01-01 12:00:35 | INFO | ALL DONE.
```

### 11.4.2 更新索引

```bash
llmsearch index update -c config.yaml

# 输出示例
# 2024-01-01 12:05:00 | INFO | The index is up to date. Exiting.
# 或
# 2024-01-01 12:05:00 | INFO | {'original_n_files': 100, 'changed_files': 2, ...}
```

### 11.4.3 交互式 Q&A（终端）

```bash
llmsearch interact llm -c doc_config.yaml -m llm_config.yaml

# 交互示例
# ENTER QUESTION >> 什么是RAG
#
# ============= SOURCES ==================
# obsidian://advanced-uri?vault=kb&filepath=笔记.md
# {'page': -1, 'score': 0.92, 'heading': '介绍'}
# ******************* BEING EXTRACT *****************
# RAG 是检索增强生成...
#
# ============= RESPONSE =================
# RAG（Retrieval-Augmented Generation）是一种...
```

### 11.4.4 启动 Web UI

```bash
llmsearch interact webapp -c config_dir/ -m llm_config.yaml

# 浏览器打开 http://localhost:8501
```

## 11.7 常见问题 FAQ

### 11.7.1 安装问题

**Q: 安装时提示 `protobuf` 版本冲突？**
A: 设置环境变量 `export PROTOCOL_BUFFERS_PYTHON_IMPLEMENTATION=python`

**Q: GPU 内存不足？**
A: 减小 `n_batch` 配置，或使用更小的嵌入模型

### 11.7.2 配置问题

**Q: 如何切换 LLM 模型？**
A: 修改 `llm.type` 和 `llm.params.model_kwargs.model_name`

**Q: 如何添加新的文档格式？**
A: 在 `scan_extensions` 中添加扩展名，Unstructured 会自动处理

### 11.7.3 运行问题

**Q: 索引更新失败，提示 Hash 文件不存在？**
A: 首次运行需使用 `index create` 创建完整索引

**Q: API 调用超时？**
A: 检查网络连接和 API Key 是否正确

**Q: 检索结果质量差？**
A: 尝试启用 HyDE 或 MultiQuery，调整 `max_k` 和 `score_cutoff`

### 11.7.4 性能问题

**Q: 索引生成太慢？**
A: 使用 GPU 加速，增大 `n_batch`

**Q: 内存占用过高？**
A: 索引更新后调用 `unload_model()` 释放内存
