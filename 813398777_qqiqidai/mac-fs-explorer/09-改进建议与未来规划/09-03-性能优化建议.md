## 2. 优化建议

### 2.1 对话历史优化

**问题**: 对话历史无限增长，增加 API 延迟和成本

**方案 1: 滑动窗口**
```python
MAX_HISTORY = 20
if len(self._chat_history) > MAX_HISTORY:
    self._chat_history = [self._chat_history[0]] + self._chat_history[-MAX_HISTORY:]
```

**方案 2: 摘要压缩**
```python
# 将早期对话摘要为单条消息
if len(self._chat_history) > THRESHOLD:
    summary = await self.summarize_history(self._chat_history[1:-10])
    self._chat_history = [self._chat_history[0], summary] + self._chat_history[-10:]
```

### 2.2 并发优化

**问题**: 评估框架串行执行任务

**方案**: 使用 `asyncio.Semaphore` 控制并发

```python
semaphore = asyncio.Semaphore(3)  # 最多 3 个并发任务

async def run_task(task):
    async with semaphore:
        wf_result = await run_workflow(...)
        pipeline_result = await run_pipeline(...)
```

### 3.3 缓存优化

**问题**: 缓存无过期策略，文件变更后缓存失效

**方案**: 基于文件修改时间的缓存键

```python
import os

def get_cache_key(file_path: str) -> str:
    mtime = os.path.getmtime(file_path)
    return f"{file_path}:{mtime}"
```

### 3.4 连接池优化

**问题**: 每次 API 调用创建新连接

**方案**: 使用 `httpx.AsyncClient` 连接池

```python
import httpx

client = httpx.AsyncClient(
    limits=httpx.Limits(max_connections=10, max_keepalive_connections=5)
)
```
