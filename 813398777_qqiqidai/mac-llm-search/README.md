## 📁 项目源码结构概览

```
src/llmsearch/
├── config.py          # 配置模型（Pydantic）
├── cli.py             # CLI 入口（Click）
├── api.py             # FastAPI 服务 + MCP
├── webapp.py          # Streamlit Web UI
├── interact.py        # 交互式 CLI Q&A
├── chroma.py          # ChromaDB 向量存储封装
├── embeddings.py      # 嵌入生成与增量更新
├── process.py         # RAG 核心编排
├── ranking.py         # 混合检索 + 重排序
├── splade.py          # SPLADE 稀疏向量
├── utils.py           # LLM 依赖组装
├── database/          # SQLite 持久化
│   ├── config.py      # SQLAlchemy 配置
│   ├── models.py      # ORM 模型
│   └── crud.py        # 数据库操作
├── models/            # LLM 模型适配
│   ├── abstract.py    # 抽象基类
│   ├── openai.py      # OpenAI 适配
│   ├── hf.py          # HuggingFace 适配
│   ├── azureopenai.py # Azure OpenAI 适配
│   ├── llama.py       # LlamaCPP 适配
│   ├── config.py      # 模型配置模型
│   └── utils.py       # 模型工厂
└── parsers/           # 文档解析器
    ├── splitter.py    # 分片调度器
    ├── markdown.py    # Markdown 解析
    ├── pdf.py         # PDF 解析
    ├── doc.py         # DOCX 解析
    ├── unstructured.py # 通用解析
    ├── tables/        # 表格解析
    └── images/        # 图片解析
```
