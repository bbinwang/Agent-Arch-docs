## 1. 架构概述

AnythingLLM 的向量数据库层采用 **策略模式（Strategy Pattern）**，通过抽象基类 `VectorDatabase` 定义统一接口，每个具体向量数据库实现继承该基类并提供自己的实现。

### 1.1 支持的向量数据库

| Provider | 文件 | 类型 | SDK |
|---------|------|------|-----|
| LanceDB | `lance.js` | 嵌入式 | @lancedb/lancedb |
| Milvus | `milvus.js` | 自托管/云服务 | @zilliz/milvus2-sdk-node |
| Qdrant | `qdrant.js` | 自托管/云服务 | @qdrant/js-client-rest |
| Pinecone | `pinecone.js` | 云服务 | @pinecone-database/pinecone |
| Weaviate | `weaviate.js` | 自托管/云服务 | weaviate-ts-client |
| Chroma | `chroma.js` | 自托管 | chromadb |
| Astra DB | `astra.js` | 云服务 | @datastax/astra-db-ts |
| PGVector | `pgvector.js` | PostgreSQL 扩展 | Prisma raw query |
| Zilliz | `zilliz.js` | 云服务 | @zilliz/milvus2-sdk-node |
| ChromaCloud | `chromacloud.js` | 云服务 | chromadb |

## 2. 抽象基类 VectorDatabase

### 2.1 接口定义

```javascript
class VectorDatabase {
  get name() { return "VectorDatabase"; }

  constructor() {
    if (this.constructor === VectorDatabase) {
      throw new Error("VectorDatabase cannot be instantiated directly");
    }
  }

  // 连接管理
  async connect() { throw new Error("Must be implemented by provider"); }
  async heartbeat() { throw new Error("Must be implemented by provider"); }

  // 命名空间管理
  async totalVectors() { throw new Error("Must be implemented by provider"); }
  async namespaceCount(namespace) { throw new Error("Must be implemented by provider"); }
  async namespace(client, namespace) { throw new Error("Must be implemented by provider"); }
  async hasNamespace(namespace) { throw new Error("Must be implemented by provider"); }
  async namespaceExists(client, namespace) { throw new Error("Must be implemented by provider"); }
  async deleteVectorsInNamespace(client, namespace) { throw new Error("Must be implemented by provider"); }

  // 文档操作
  async addDocumentToNamespace(namespace, documentData, fullFilePath, skipCache) { throw new Error("Must be implemented by provider"); }
  async deleteDocumentFromNamespace(namespace, docId) { throw new Error("Must be implemented by provider"); }

  // 检索
  async similaritySearch(params) { throw new Error("Must be implemented by provider"); }
  async getVectors(namespace) { throw new Error("Must be implemented by provider"); }
  async getVectorById(namespace, vectorId) { throw new Error("Must be implemented by provider"); }
}
```

**设计要点**：
- **构造函数保护**：防止直接实例化基类。
- **接口契约**：所有方法抛出 `"Must be implemented by provider"`，强制子类实现。
- **命名空间隔离**：通过 `namespace` 参数实现多租户向量隔离（每个 Workspace 一个 namespace）。

### 2.2 工厂函数

```javascript
// server/utils/helpers/index.js
function getVectorDbClass(getExactly = null) {
  const VECTOR_DB = getExactly || process.env.VECTOR_DB || "lancedb";
  // ... 根据 VECTOR_DB 环境变量加载对应 Provider 类
  return require(`../vectorDbClass/${VECTOR_DB}`).default;
}
```

**设计模式**：工厂模式。根据环境变量动态加载对应 Provider 实现，上层代码无需关心具体实现。

## 3. LanceDB 实现（默认 Provider）

### 3.1 特点

- **嵌入式**：无需独立服务，数据存储在本地文件。
- **默认选择**：AnythingLLM 默认使用 LanceDB，降低部署复杂度。
- **基于 Lance 列式存储**：高性能向量检索。

### 3.2 核心方法实现

```javascript
const lancedb = require("@lancedb/lancedb");

class LanceDB extends VectorDatabase {
  constructor() {
    super();
    this.name = "LanceDB";
  }

  async connect() {
    const dbPath = path.resolve(__dirname, "../../../storage/vector-cache");
    const db = await lancedb.connect(dbPath);
    return { client: db };
  }

  async similaritySearch({ namespace, input, topN = 4 }) {
    const { client } = await this.connect();
    const table = await client.openTable(namespace);
    const results = await table.search(input).limit(topN).execute();
    return results.map(r => ({
      pageContent: r.pageContent,
      metadata: r.metadata,
      score: r._lance_score,
    }));
  }
}
```

**注意**：上述为简化示意，实际实现更复杂（包含缓存、错误处理等）。

## 4. 其他 Provider 实现要点

### 4.1 Qdrant

```javascript
const { QdrantClient } = require("@qdrant/js-client-rest");

class QdrantDB extends VectorDatabase {
  async connect() {
    const client = new QdrantClient({
      url: process.env.QDRANT_ENDPOINT,
      apiKey: process.env.QDRANT_API_KEY,
    });
    return { client };
  }

  async similaritySearch({ namespace, input, topN }) {
    const response = await this.client.search(namespace, {
      vector: input,
      limit: topN,
      with_payload: true,
    });
    return response.map(r => ({
      pageContent: r.payload.pageContent,
      metadata: r.payload.metadata,
      score: r.score,
    }));
  }
}
```

### 4.2 Pinecone

```javascript
const { PineconeClient } = require("@pinecone-database/pinecone");

class PineconeDB extends VectorDatabase {
  async similaritySearch({ namespace, input, topN }) {
    const index = this.client.Index(process.env.PINECONE_INDEX);
    const queryResponse = await index.query({
      queryRequest: {
        vector: input,
        topK: topN,
        namespace: namespace,
        includeMetadata: true,
      },
    });
    return queryResponse.matches.map(m => ({
      pageContent: m.metadata.pageContent,
      metadata: m.metadata,
      score: m.score,
    }));
  }
}
```

### 4.3 Milvus / Zilliz

```javascript
const milvus = require("@zilliz/milvus2-sdk-node");

class MilvusDB extends VectorDatabase {
  async similaritySearch({ namespace, input, topN }) {
    const results = await this.client.search({
      collection_name: namespace,
      vectors: [input],
      limit: topN,
      params: { nprobe: 16 },
    });
    return results.results.map(r => ({
      pageContent: r.entity.pageContent,
      metadata: r.entity.metadata,
      score: r.score,
    }));
  }
}
```

```javascript
    chunk: number,        // 分块序号
    // ...
  },

```

## 6. 潜在问题与改进建议

| 问题 | 影响 | 建议 |
|------|------|------|
| 每次查询都新建连接 | 性能开销 | 使用连接池或长连接 |
| 无缓存层 | 重复查询消耗资源 | 添加 Redis 缓存热点查询 |
| 向量维度硬编码 | 切换嵌入模型时出错 | 动态检测维度并迁移 |
| 无批量检索接口 | 批量场景效率低 | 添加 `batchSimilaritySearch` |
| 错误处理不一致 | 不同 Provider 错误格式不同 | 统一错误封装 |
