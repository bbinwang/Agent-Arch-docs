## 10.1 环境准备

### 10.1.1 系统要求

| 项目 | 最低要求 | 推荐配置 |
|------|---------|---------|
| **操作系统** | macOS / Linux / Windows (WSL2) | macOS 14+ / Ubuntu 22.04+ |
| **Python** | 3.10+ | 3.12+ |
| **Node.js** | 18+（仅 Generative UI 模板需要） | 20 LTS |
| **内存** | 4 GB | 8 GB+ |
| **磁盘** | 2 GB 可用空间 | 5 GB+（含模型/向量库） |
| **网络** | 可访问 LLM API | 稳定高速网络 |

### 10.1.2 工具安装

#### Python 环境

```bash
# 安装 Python 3.12（推荐使用 pyenv）
# macOS
brew install python@3.12

# Ubuntu
sudo apt update
sudo apt install python3.12 python3.12-venv

# 验证
python3 --version  # Python 3.12.x
```

#### 虚拟环境

```bash
# 创建虚拟环境
python3 -m venv .venv

# 激活虚拟环境
source .venv/bin/activate  # macOS/Linux
.venv\Scripts\activate     # Windows

# 退出虚拟环境
deactivate
```

#### Node.js（仅 Generative UI 模板需要）

```bash
# 安装 Node.js 20 LTS
# macOS
brew install node@20

# Ubuntu
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install nodejs

# 验证
node --version  # v20.x.x
```

#### pnpm（推荐）

```bash
npm install -g pnpm
```

### 10.1.3 获取代码

```bash

git clone https://github.com/Shubhamsaboo/awesome-llm-apps.git
cd awesome-llm-apps

# 查看目录结构
```

## 10.2 本地运行

### 10.2.1 Starter 模板（Python + Streamlit）

以 `ai_travel_agent` 为例：

```bash
# 进入子项目
cd starter_ai_agents/ai_travel_agent

# 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate

# 安装依赖
pip install -r requirements.txt

# 运行
streamlit run travel_agent.py
```

**预期输出**：
```
You can now view your Streamlit app in your browser.

Local URL: http://localhost:8501
Network URL: http://192.168.x.x:8501
```

打开浏览器访问 `http://localhost:8501`，输入 API Key 即可使用。

### 10.2.2 Generative UI 模板（Next.js）

以 `generative-ui-starter-project` 为例：

```bash
cd generative_ui_agents/generative-ui-starter-project

# 安装 Node 依赖
pnpm install

# 安装 Agent 依赖
pnpm run install:agent

# 启动开发模式（UI + Agent 并行）
pnpm run dev
```

**预期输出**：
```
 ✓ Started server on 0.0.0.0:3000
 ✓ Agent running on port 8123
```

### 10.2.3 Always-on Agent（FastAPI）

```bash
cd always_on_agents/always_on_hn_briefing_agent

pip install -r requirements.txt

# 启动调度 API
uvicorn scheduler_api:app --host 0.0.0.0 --port 8000 --reload

# 预览 Brief
curl http://localhost:8000/agent-scout/dry-run

# 触发执行
curl -X POST http://localhost:8000/agent-scout/trigger \
  -H "Content-Type: application/json" \
  -d '{"dry_run": true, "top_n": 5}'
```

### 10.2.4 MCP Agent

```bash
cd mcp_ai_agents/browser_mcp_agent

pip install -r requirements.txt

# 确保 Playwright MCP 可用
npx @playwright/mcp@latest --help

# 运行
streamlit run main.py
```

## 10.3 API Key 配置

### 10.3.1 必需 API Key

| API Key | 获取地址 | 免费额度 |
|---------|---------|---------|
| **OpenAI** | https://platform.openai.com/api-keys | $5 试用额度 |
| **Google AI** | https://aistudio.google.com/app/apikey | 免费（限流） |
| **SerpAPI** | https://serpapi.com/dashboard | 100 次/月免费 |
| **Firecrawl** | https://firecrawl.dev | 500 次免费 |
| **Anthropic** | https://console.anthropic.com/settings/keys | 需充值 |

### 10.3.2 配置方式

#### 方式 1：环境变量（推荐）

```bash
# ~/.bashrc 或 ~/.zshrc
export OPENAI_API_KEY="sk-..."
export GOOGLE_API_KEY="AIza..."
export SERPAPI_API_KEY="..."

# 生效
source ~/.bashrc
```

#### 方式 2：.env 文件

```bash
# 在子项目根目录创建 .env
echo "OPENAI_API_KEY=sk-..." > .env

# 确保 .gitignore 包含 .env
echo ".env" >> .gitignore
```

#### 方式 3：Streamlit 输入框

直接在应用 UI 中输入（仅本地开发适用，不要部署到生产）。

## 10.4 调试技巧

### 10.4.1 Python 调试

#### 使用 print 调试

```python
import logging
logging.basicConfig(level=logging.DEBUG)

# 在关键位置添加日志
logger = logging.getLogger(__name__)
logger.debug(f"Research results: {research_results.content[:200]}...")
```

#### 使用 pdb 断点

```python
import pdb; pdb.set_trace()  # 断点

# 或使用 breakpoint()（Python 3.7+）
breakpoint()
```

#### 使用 VS Code 调试

```json
// .vscode/launch.json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Current File",
            "type": "debugpy",
            "request": "launch",
            "program": "${file}",
            "console": "integratedTerminal",
            "justMyCode": false

    ]
}
```

```bash
# 1. Fork 仓库
# 在 GitHub 上点击 Fork 按钮

# 2. 克隆 Fork

# 4. 开发
# 在对应分类目录下创建新子项目

# 6. 推送
git push origin add-ai-xxx-agent

# 在 GitHub 上点击 "Compare & pull request"
```

### 10.7.2 新模板标准结构

```
new_agent_name/
├── README.md                              ← 必须
├── main.py 或 app.py                      ← 必须（可执行入口）
├── requirements.txt                       ← 必须（Python 模板）
├── .env.example                           ← 推荐（环境变量模板）
├── assets/                                ← 可选（图片等资源）
└── tests/                                 ← 推荐（测试）
```

### 10.7.4 代码规范

| 项目 | 规范 |
|------|------|
| **命名** | `snake_case` 变量/函数，`PascalCase` 类 |
| **类型注解** | 所有函数必须有类型提示 |
| **Docstring** | 所有公开函数必须有 docstring |
| **行长度** | 最大 100 字符 |
| **导入顺序** | 标准库 → 第三方 → 本地 |
| **错误处理** | 使用 try/except，避免裸 except |

## 10.8 常见问题（FAQ）

### 10.8.1 运行问题

| 问题 | 解决方案 |
|------|---------|
| `ModuleNotFoundError` | 运行 `pip install -r requirements.txt` |
| `API Key invalid` | 检查 Key 是否正确，是否有额度 |
| `Port already in use` | 更换端口或关闭占用进程 |
| `Streamlit not found` | 确保虚拟环境已激活 |

### 10.8.2 API 问题

| 问题 | 解决方案 |
|------|---------|
| `RateLimitError` | 降低请求频率或升级 API 套餐 |
| `TimeoutError` | 检查网络连接，增加 timeout 参数 |
| `AuthenticationError` | 检查 API Key 是否正确/过期 |

### 10.8.3 开发问题

| 问题 | 解决方案 |
|------|---------|
| 如何选择模板？ | 参考 10.6 分类导览 |
| 如何切换 LLM？ | 修改 `model=OpenAIChat(id="...")` 中的模型 ID |
| 如何添加新工具？ | 在 Agent 的 `tools=[...]` 列表中添加 |
| 如何调试 Agent？ | 使用 `debug_mode=True` 或添加日志 |
