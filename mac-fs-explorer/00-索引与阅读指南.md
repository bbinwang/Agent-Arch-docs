## 1. 文档说明

### 1.1 文档目的

本文档是对 **fs-explorer** 项目的完整技术架构分析与代码讲解文档。其核心目标包括：

1. **架构透明化**: 通过 C4 模型将系统的层级结构、模块划分、交互方式以可视化方式呈现，使任何技术背景的读者都能在 30 分钟内建立对项目全貌的认知。
2. **代码深度走读**: 对 17 个核心源文件进行逐函数级别的详细讲解，包括功能说明、参数语义、返回值契约、核心逻辑、设计模式识别、潜在问题与改进建议。
3. **流程可视化**: 使用 Mermaid 语法绘制 35+ 个流程图、时序图、类图、依赖图，覆盖从 CLI 启动到 Agent 决策循环、从 RAG 索引到评估统计的完整链路。
4. **知识沉淀**: 通过架构决策记录（ADR）文档化关键设计选择的历史背景与权衡逻辑，避免后续维护者重复踩坑。
5. **开发者赋能**: 提供完整的本地运行、调试、测试上手指南，降低新贡献者的入门门槛。

## 2. 术语表

### 2.1 核心领域术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 文件系统探索 | File System Exploration | 通过 AI 智能体递归遍历目录结构，定位、读取、分析文件内容以完成用户任务的过程 |
| 智能体 | Agent | 在本项目中特指 `FsExplorerAgent`，一个基于 LLM 的决策实体，能够根据上下文选择调用工具、深入子目录、询问用户或返回最终结果 |
| 工具调用 | Tool Call | Agent 调用预定义函数（read/grep/glob/parse_file/check_api_key）与文件系统交互的动作 |
| 工作流 | Workflow | 基于 `llama-index-workflows` 框架定义的有状态步骤编排，本项目包含 4 个步骤（start_exploration, go_deeper_action, tool_call_action, receive_human_answer） |
| 事件 | Event | 工作流中步骤间传递的消息载体，包括 StartEvent、StopEvent、InputRequiredEvent、HumanResponseEvent 等 |
| 容器 | Container | C4 模型中的第二层概念，指可独立部署的进程或服务（如 CLI 应用、向量数据库） |
| 组件 | Component | C4 模型中的第三层概念，指容器内部的模块或类（如 Agent、Embedder、VectorDB） |

### 2.2 技术栈术语

| 术语 | 英文 | 定义 |
|------|------|------|
| 混合检索 | Hybrid Search | 同时使用 Dense（稠密）和 Sparse（稀疏）两种向量进行检索，并通过 RRF 融合结果的搜索策略 |
| 倒数排名融合 | Reciprocal Rank Fusion (RRF) | 一种无监督的多路检索结果融合算法，公式为 `score(d) = Σ 1/(k + rank_i(d))`，其中 k 为平滑常数 |
| 稠密嵌入 | Dense Embedding | 通过神经网络模型（如 OpenAI text-embedding-3-small）生成的高维连续向量表示 |
| 稀疏嵌入 | Sparse Embedding | 通过词频统计模型（如 BM25）生成的高维稀疏向量表示，非零维度对应词项 |
| 分块 | Chunking | 将长文本切分为固定大小、带重叠的短文本块，以适应嵌入模型的上下文窗口限制 |
| LLM-as-Judge | LLM-as-Judge | 使用大语言模型作为评判者，对生成的回答进行自动化评估的方法 |
| 结构化输出 | Structured Output | 通过 JSON Schema 约束 LLM 输出格式，确保返回结果可被程序解析 |
| 事件驱动架构 | Event-Driven Architecture (EDA) | 基于事件的产生、传播、消费来驱动系统行为的架构模式 |

### 2.3 项目特定术语

| 术语 | 定义 |
|------|------|
| `explore run` | CLI 命令，启动 Agent 执行探索任务 |
| `explore load-cache` | CLI 命令，预解析目录中的文件并加载到持久缓存 |
| `explore get-cached` | CLI 命令，获取已缓存文件的内容 |
| `run-eval` | CLI 命令，运行双框架对比评估 |
| `get-stats` | CLI 命令，从评估结果生成统计报告 |
| `cache-arxiv` | CLI 命令，将 arXiv 论文摘要缓存到磁盘 |
| `GoDeeper` | Agent 动作类型，表示进入子目录继续探索 |
| `AskHuman` | Agent 动作类型，表示向用户请求澄清 |
| `WorkflowState` | 工作流状态对象，记录初始任务和当前目录 |
| `SimpleReranker` | RRF 重排序器实现类 |
