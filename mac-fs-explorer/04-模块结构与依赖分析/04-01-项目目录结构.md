## 4. 目录职责说明

### 4.1 根目录

| 文件/目录 | 职责 |
|-----------|------|
| `pyproject.toml` | 定义项目元数据、依赖、脚本入口、workspace 成员 |
| `uv.lock` | 锁定所有依赖的精确版本，确保可复现构建 |
| `Makefile` | 提供统一的构建命令（test/lint/format/typecheck/build） |
| `.python-version` | 指定开发用 Python 版本（3.13） |
| `.gitignore` | 忽略 Python 虚拟环境、缓存、构建产物、日志 |
| `.pre-commit-config.yaml` | 配置 Git 提交前自动检查（冲突、YAML、私钥等） |

### 4.2 src/fs_explorer/

| 文件 | 职责 |
|------|------|
| `__init__.py` | 包初始化（空文件，标记为 Python 包） |
| `main.py` | CLI 入口，定义 `explore` 命令，渲染事件到终端 |
| `agent.py` | Agent 核心，封装 Gemini 客户端和工具调用 |
| `workflow.py` | 工作流编排，定义 4 步状态机和事件类型 |
| `fs.py` | 文件系统工具函数（read/grep/glob/parse_file/check_api_key） |
| `models.py` | Pydantic 数据模型（Action 体系、WorkflowState） |
| `caching.py` | DiskCache 封装（ParsedFileCache）和批量缓存加载 |

### 4.3 packages/rag-starterkit/

| 文件 | 职责 |
|------|------|
| `pipeline.py` | RAG 流水线编排，管理索引和检索两个阶段 |
| `parse.py` | 文档解析策略（实时解析 / 缓存加载） |
| `chunk.py` | 文本分块，封装 Chonkie SentenceChunker |
| `embed.py` | 嵌入生成，支持 Dense（OpenAI）和 Sparse（FastEmbed） |
| `vectordb.py` | Qdrant 封装，支持混合检索和 RRF 重排序 |
| `llm_filter.py` | LLM 文件过滤和回答生成 |

### 4.4 packages/eval-framework/

| 文件 | 职责 |
|------|------|
| `main.py` | CLI 入口，定义 `run-eval` 和 `get-stats` 命令 |
| `evaluate.py` | 评估执行，遍历数据集并调用双框架运行器 |
| `run.py` | 双框架运行器（run_workflow / run_pipeline） |
| `stats.py` | 统计聚合和 Markdown 报告生成 |
| `_templating.py` | 轻量模板引擎（`{{variable}}` 替换） |

### 4.5 packages/cache-arxiv/

| 文件 | 职责 |
|------|------|
| `main.py` | CLI 入口，定义 `cache-arxiv` 命令 |
| `utils.py` | 缓存逻辑，遍历文本文件并写入 DiskCache |

### 4.6 tests/

| 文件 | 职责 |
|------|------|
| `conftest.py` | 测试配置，提供 MockGenAIClient 等 Fixtures |
| `test_agent.py` | Agent 单元测试（初始化、配置、决策） |
| `test_fs.py` | 文件系统工具测试（read/grep/glob/parse_file） |
| `test_models.py` | 模型测试（Action 类型转换、参数解析） |
| `test_e2e.py` | 端到端测试（完整工作流执行） |

### 4.7 data/

| 文件/目录 | 职责 |
|-----------|------|
| `dr_a_*.pdf` | 示例 PDF 文件（用于演示 Agent 探索） |
| `testfile.txt` | 测试文本文件 |
| `benchmark/` | 基准测试数据（问答对、PDF、评估结果） |
| `benchmark/arxiv-100-papers/` | 100 篇 arXiv 论文（大规模评估） |
| `benchmark/arxiv-1000-papers/` | 1000 篇 arXiv 论文（超大规模评估） |
