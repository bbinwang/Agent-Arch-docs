## 1. 环境准备

### 1.1 安装 Python 3.10+

```bash
# 使用 pyenv
pyenv install 3.13
pyenv local 3.13

# 或使用系统 Python
python3 --version  # >= 3.10
```

### 1.2 安装 uv

```bash
# macOS/Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# 验证
uv --version
```

### 2.1 克隆仓库


```bash

cp .env.example .env

# 编辑 .env 添加 API Keys

```

## 8. 添加新工具

### 8.1 定义工具函数

```python
# fs.py
def list_directory(directory: str) -> str:
    """List all files in a directory."""
    if not os.path.isdir(directory):
        return f"No such directory: {directory}"
    return "\n".join(os.listdir(directory))
```

### 8.2 注册工具

```python
# agent.py
from .fs import list_directory

TOOLS: dict[Tools, Callable] = {
    ...,
    "list_directory": list_directory,
}
```

### 8.3 更新类型别名

```python
# models.py
Tools: TypeAlias = Literal[..., "list_directory"]
```

### 8.4 更新系统提示

```python
SYSTEM_PROMPT = """
...
+ `list_directory`: list all files in a directory...
"""
```

### 8.5 添加测试

```python

    result = list_directory("tests/testfiles")
    assert "file1.txt" in result
```
