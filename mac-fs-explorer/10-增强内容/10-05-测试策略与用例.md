## 1. 测试策略

### 1.1 测试金字塔

```
        /  E2E  \          ← 少量（1-2 个）
       /--------\
      / Integration \       ← 中等（5-10 个）
     /--------------\
    /  Unit Tests    \     ← 大量（20+ 个）
   /------------------\
```

| 类型 | 覆盖范围 | 工具 | 数量 |

| 集成测试 | 多模块协作 | pytest | 5+ |
| E2E 测试 | 完整工作流 | pytest + Mock | 2+ |

**测试流程**:
```python
async def test_e2e():
    start_event = InputEvent(task="找到 Python 文件并解释")
    runner = WorkflowTestRunner(workflow=workflow)
    result = await runner.run(start_event=start_event)
    
    assert isinstance(result.result, ExplorationEndEvent)
    assert result.result.error is None
    assert result.result.final_result is not None
    assert len(result.collected) > 1
```

## 5. 测试最佳实践

### 5.1 使用 Fixtures

```python
@pytest.fixture
def mock_agent():
    agent = FsExplorerAgent(api_key="test-key")
    agent._client = MockGenAIClient(...)
    return agent
```

### 5.2 参数化测试

```python
@pytest.mark.parametrize("pattern,expected", [
    (r"test", "MATCHES..."),
    (r"notfound", "No matches found"),
])
def test_grep(pattern, expected):
    result = grep_file_content("test.txt", pattern)
    assert expected in result
```

### 5.3 异步测试

```python
@pytest.mark.asyncio
async def test_async_function():
    result = await async_function()
    assert result is not None
```
