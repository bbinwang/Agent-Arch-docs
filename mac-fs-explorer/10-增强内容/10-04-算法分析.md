## 1. 倒数排名融合（RRF）

### 1.1 算法描述

RRF 是一种无监督的多路检索结果融合算法，通过计算每个文档在多路结果中的排名倒数之和来打分。

### 1.2 伪代码

```
function RRF(dense_results, sparse_results, k=60, limit=1):
    rrf_scores = empty map
    
    for rank, result in enumerate(dense_results, start=1):
        content = result.content
        rrf_scores[content] += 1 / (k + rank)
    
    for rank, result in enumerate(sparse_results, start=1):
        content = result.content
        rrf_scores[content] += 1 / (k + rank)
    
    # 去重并保留元数据
    results_map = deduplicate(dense_results, sparse_results)
    
    # 按 RRF 分数排序
    sorted_results = sort_by_score(results_map, rrf_scores)
    
    return sorted_results[:limit]
```

### 1.3 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| Dense 排名累加 | O(n) | O(n) |
| Sparse 排名累加 | O(m) | O(m) |
| 去重合并 | O(n + m) | O(n + m) |
| 排序 | O(p log p) | O(p) |
| **总计** | **O(n + m + p log p)** | **O(n + m)** |

其中 n = dense 结果数，m = sparse 结果数，p = 去重后总数。

### 1.4 优化建议

1. **堆排序**: 使用 `heapq.nlargest(limit, ...)` 替代全量排序，复杂度降为 O(p log limit)
2. **并行计算**: 两路排名累加可并行执行
3. **增量更新**: 对于流式结果，可增量更新 RRF 分数

## 2. Agent 决策循环

### 2.1 算法描述

Agent 通过不断循环"感知 → 决策 → 行动 → 观察"来完成任务。

### 2.2 伪代码

```
function AgentDecisionLoop(task, max_steps=100):
    history = [SystemPrompt]
    history.append(TaskDescription(task))
    
    for step in range(max_steps):
        action = LLM.generate(history)
        history.append(action)
        
        if action.type == "stop":
            return action.final_result
        
        if action.type == "toolcall":
            result = execute_tool(action.tool_name, action.tool_input)
            history.append(ToolResult(result))
        
        if action.type == "godeeper":
            dir_description = describe_directory(action.directory)
            history.append(DirectoryDescription(dir_description))
        
        if action.type == "askhuman":
            answer = wait_for_user_input(action.question)
            history.append(HumanAnswer(answer))
    
    return TimeoutError("Max steps exceeded")
```

### 2.3 复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 单次决策 | O(n) + API | n = 历史长度 |
| 完整循环 | O(k × n) | k = 步数 |

### 2.4 优化建议

1. **历史截断**: 保留最近 N 轮对话，避免上下文溢出
2. **摘要压缩**: 将早期对话摘要为单条消息
3. **提前终止**: 检测循环模式，提前退出

## 3. 文本分块（SentenceChunker）

### 3.1 算法描述

基于句子边界的文本分块，确保每块在句子边界处切分，并有固定重叠。

### 3.2 伪代码

```
function ChunkText(text, chunk_size=2048, chunk_overlap=200):
    sentences = split_into_sentences(text)
    chunks = []
    current_chunk = ""
    
    for sentence in sentences:
        if len(current_chunk) + len(sentence) > chunk_size:
            chunks.append(current_chunk)
            # 保留末尾 overlap 字符
            current_chunk = current_chunk[-chunk_overlap:] + sentence
        else:
            current_chunk += sentence
    
    if current_chunk:
        chunks.append(current_chunk)
    
    return chunks
```

### 3.3 复杂度分析

| 操作 | 时间复杂度 | 空间复杂度 |
|------|-----------|-----------|
| 句子分割 | O(n) | O(n) |
| 分块 | O(n) | O(n) |
| **总计** | **O(n)** | **O(n)** |

### 3.4 优化建议

1. **动态块大小**: 根据内容密度调整块大小
2. **语义分块**: 基于语义连贯性而非固定字符数
3. **并行分块**: 多文档并行处理

## 4. 并发文件解析

### 4.1 算法描述

使用信号量限制并发度，批量解析文件并缓存。

### 4.2 伪代码

```
function ParseAndCache(files, max_concurrency=5):
    semaphore = Semaphore(max_concurrency)
    
    async def parse_job(file):
        async with semaphore:
            result = await LlamaParse(file)
            cache.add(file, result)
    
    await asyncio.gather(*[parse_job(f) for f in files])
```

### 4.3 复杂度分析

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 总时间 | O(n / c × t) | n = 文件数, c = 并发度, t = 单次解析 |
| 空间复杂度 | O(c) | 并发协程数 |

### 4.4 优化建议

1. **动态并发**: 根据 API 响应动态调整并发度
2. **优先级队列**: 优先解析重要文件
3. **断点续传**: 记录已解析文件，支持中断恢复
