## 2. explore run

### 2.1 命令定义

```bash
explore run --task "找到包含投诉的 PDF 文件"
explore run -t "总结所有 Python 文件的功能"
```

### 2.2 参数

| 参数 | 简写 | 类型 | 必需 | 说明 |
|------|------|------|------|------|
| `--task` | `-t` | str | ✅ | Agent 要执行的任务描述 |

### 2.3 执行流程

```
explore run --task "任务描述"
    ↓
解析参数
    ↓
asyncio.run(run_workflow(task))
    ↓
启动 FsExplorerWorkflow
    ↓
订阅事件流
    ↓
渲染事件到终端
    ↓
返回最终结果
```

### 2.4 输出示例

```
Working on your request...

╭─ Tool Call ──────────────────────────────────────────────╮
│ Calling tool `read` with input:                           │
│ {                                                         │
│   "file_path": "data/testfile.txt"                        │
│ }                                                         │
│ The tool call is motivated by: I need to check the file   │
╰───────────────────────────────────────────────────────────╯

╭─ Final result ───────────────────────────────────────────╮
│ The file contains...                                      │
╰───────────────────────────────────────────────────────────╯
```

## 3. explore load-cache

### 3.1 命令定义

```bash
explore load-cache --directory ./data --recursive
explore load-cache -d . -r --skip tmp --skip logs
```

### 3.2 参数

| 参数 | 简写 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--directory` | `-d` | str | `.` | 目标目录 |
| `--recursive` | `-r` | bool | False | 是否递归 |
| `--skip` | `-s` | list[str] | [] | 跳过的文件/目录 |

---

## 4. explore get-cached

### 4.1 命令定义

```bash
explore get-cached --file data/testfile.txt
explore get-cached -f data/testfile.txt --max 5000
```

### 4.2 参数

| 参数 | 简写 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--file` | `-f` | str | 必需 | 缓存文件路径 |
| `--max` | `-m` | int | 10000 | 最大显示字符数 |

---

## 5. run-eval

### 5.1 命令定义

```bash
run-eval --dataset-file questions_and_answers.json
run-eval -df qa.json --advanced
```

### 5.2 参数

| 参数 | 简写 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--dataset-file` | `-df` | str | 必需 | 数据集 JSON 文件 |
| `--advanced` | - | bool | False | 高级模式（arXiv 论文） |
| `--output` | `-o` | str | results.json | 输出文件 |

---

## 6. get-stats

### 6.1 命令定义

```bash
get-stats
get-stats -rf results.json -j stats.json -r report.md
```

### 6.2 参数

| 参数 | 简写 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--results-file` | `-rf` | str | results.json | 评估结果文件 |
| `--output-json` | `-j` | str | statistics.json | JSON 统计输出 |
| `--output-report` | `-r` | str | report.md | Markdown 报告输出 |

---

## 7. cache-arxiv

### 7.1 命令定义

```bash
cache-arxiv
cache-arxiv -d ./papers -c tmp/cache -t texts
```

### 7.2 参数

| 参数 | 简写 | 类型 | 默认值 | 说明 |
|------|------|------|--------|------|
| `--directory` | `-d` | str | None | 基础目录 |
| `--cache-dir` | `-c` | str | None | 缓存目录 |
| `--texts-dir` | `-t` | str | None | 文本目录 |
