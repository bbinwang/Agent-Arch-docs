## 1. Google Gemini API

### 1.1 接口定义

```python
from google.genai import Client

client = Client(api_key="...")
response = await client.aio.models.generate_content(
    model="gemini-3-flash-preview",
    contents=[...],  # list[Content]
    config={
        "response_mime_type": "application/json",
        "response_json_schema": {...},
    },
)
```

### 1.2 请求参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `model` | str | 模型名称 |
| `contents` | list[Content] | 对话历史 |
| `config.response_mime_type` | str | 响应格式（application/json） |
| `config.response_json_schema` | dict | JSON Schema 约束 |

### 1.3 响应格式

```json
{
  "candidates": [
    {
      "content": {
        "role": "assistant",
        "parts": [{"text": "{\"action\": {...}, \"reason\": \"...\"}"}]
      }
    }
  ],
  "text": "{\"action\": {...}, \"reason\": \"...\"}"
}
```

## 2. OpenAI API

### 2.1 嵌入接口

```python
from openai import AsyncOpenAI

client = AsyncOpenAI(api_key="...")
embeddings = await client.embeddings.create(
    input=["text1", "text2"],
    model="text-embedding-3-small",
    dimensions=768,
)
```

### 2.2 结构化输出接口

```python
response = await client.responses.parse(
    text_format=Evaluation,  # Pydantic 模型
    input=[message],
    model="gpt-4.1",
)
return response.output_parsed  # Evaluation 实例
```

## 3. LlamaParse API

### 3.1 接口定义

```python
from llama_cloud_services import LlamaParse

parser = LlamaParse(
    api_key="...",
    result_type=ResultType.TXT,
    fast_mode=True,
)
result = await parser.aparse(file_path="document.pdf")
text = await result.aget_text()
```

### 3.2 参数

| 参数 | 类型 | 说明 |
|------|------|------|
| `api_key` | str | Llama Cloud API Key |
| `result_type` | ResultType | 输出格式（TXT/MD/JSON） |
| `fast_mode` | bool | 快速模式（牺牲精度换速度） |
