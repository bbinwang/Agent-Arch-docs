# 08-01 — 本地开发环境搭建

> **本章内容**: 本地开发环境配置、依赖安装、运行
> **预估字数**: ~5,000 字

---

## 1. 前置要求

| 工具 | 版本 | 用途 |
|------|------|------|
| Python | >= 3.10 | 运行环境 |
| uv | >= 0.9.10 | 包管理 |
| Docker | 最新 | Qdrant 容器 |

---

## 2. 安装步骤

### 2.1 克隆仓库

```bash
git clone https://github.com/run-llama/fs-explorer
cd fs-explorer
```

### 2.2 安装依赖

```bash
uv pip install .
# 或安装开发依赖
uv pip install -e ".[dev]"
```

### 2.3 配置环境变量

```bash
export GOOGLE_API_KEY="your-gemini-api-key"
export OPENAI_API_KEY="your-openai-api-key"
export LLAMA_CLOUD_API_KEY="your-llamaparse-api-key"
```

---

## 3. 启动 Qdrant

```bash
cd packages/eval-framework
docker compose up -d
```

**验证**:
```bash
curl http://localhost:6333/collections
```

---

## 4. 运行测试

```bash
make test        # 运行测试
make lint        # 代码检查
make format      # 代码格式化
make typecheck   # 类型检查
make build       # 构建包
```

---

## 5. 运行示例

```bash
# Agent 探索
explore run --task "找到包含订单的 PDF 文件"

# 预加载缓存
explore load-cache --directory ./data --recursive

# 运行评估
cd data/benchmark
run-eval -df questions_and_answers.json
get-stats
```
