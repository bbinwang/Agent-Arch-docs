## 1. 日志配置

## 4. 改进建议

### 4.1 结构化日志

```python
import structlog
logger = structlog.get_logger()
logger.info("tool_called", tool_name="read", file_path="test.txt")
```

### 4.2 指标收集

```python
# 使用 Prometheus 客户端
from prometheus_client import Counter
tool_calls = Counter("fs_explorer_tool_calls_total", "Total tool calls", ["tool_name"])
```

### 4.3 分布式追踪

```python
# 使用 OpenTelemetry
from opentelemetry import trace
tracer = trace.get_tracer(__name__)
with tracer.start_as_current_span("agent_decision"):
    action = await agent.take_action()
```
