## 1. 架构概述

聊天 UI 是 AnythingLLM 前端 **最复杂的交互模块**，负责：
1. 聊天消息展示（Markdown 渲染、代码高亮、引用来源）
2. SSE 流式响应处理
3. 用户输入（文本、附件、语音）
4. 聊天历史加载与滚动
5. 工作空间与线程切换
6. TTS 朗读与 STT 语音输入

### 1.1 核心组件树

```
WorkspaceChat（页面）
├── Sidebar（侧边栏导航）
```

## 2. WorkspaceChat 组件

### 2.1 功能

`frontend/src/components/WorkspaceChat/index.jsx` 是聊天页面的核心组件，负责：
1. 加载聊天历史
2. 管理工作空间/线程切换
3. 处理文件拖拽上传
4. 协调 TTS 自动朗读

### 2.2 核心状态

```jsx
export default function WorkspaceChat({ loading, workspace }) {
  const { threadSlug = null } = useParams();
  const navigate = useNavigate();
  const [loaded, setLoaded] = useState(null);  // 当前加载的聊天
  const [dragging, setDragging] = useState(false); // 拖拽状态
  const pendingFilesRef = useRef([]);           // 待上传文件

  // 加载聊天历史
  async function getHistory() {
    if (loading) return;
    if (!workspace?.slug) {
      setLoaded({ key: "none", workspace: null, history: [] });
      return false;
    }

    const chatHistory = threadSlug
      ? await Workspace.threads.chatHistory(workspace.slug, threadSlug)
      : await Workspace.chatHistory(workspace.slug);

    setLoaded({
      key: `${workspace.slug}:${threadSlug ?? "default"}`,
      workspace,
      threadSlug,
      history: chatHistory,
    });
  }

  useEffect(() => { getHistory(); }, [workspace, loading, threadSlug]);
}
```

**设计要点**：
- **`loaded` 状态滞后于 props**：切换工作空间时，旧聊天保持显示直到新聊天加载完成，避免闪烁。
- **`pendingFilesRef`**：处理无线程时的文件上传（先创建线程再上传）。

## 3. SSE 流式处理

### 3.1 流式请求

前端使用 `@microsoft/fetch-event-source` 库处理 SSE：

```jsx
import { fetchEventSource } from "@microsoft/fetch-event-source";

async function streamChat(workspaceSlug, message, onMessage, onError) {
  await fetchEventSource(`/api/workspace/${workspaceSlug}/stream-chat`, {
    method: "POST",
    headers: { "Content-Type": "application/json" },
    body: JSON.stringify({ message }),
    onmessage(event) {
      const data = JSON.parse(event.data);
      onMessage(data);
    },
    onerror(error) {
      onError(error);
    },
    openWhenHidden: true, // 后台保持连接
  });
}
```

### 3.2 消息处理

```jsx
function handleStreamMessage(data) {
  switch (data.type) {
    case "textResponse":
      if (data.textResponse) {
        // 追加到当前消息
        appendToCurrentMessage(data.textResponse);
      }
      break;
    case "sources":
      // 显示引用来源
      setSources(data.sources);
      break;
    case "abort":
      // 错误终止
      showError(data.error);
      break;
    case "close":
      // 流结束
      finalizeMessage();
      break;
    case "modelRouteNotification":
      // 路由通知
      showRouteNotification(data.routedTo);
      break;
  }
}
```

## 4. ChatBubble 组件

### 4.1 功能

`frontend/src/components/ChatBubble/` 负责单条消息的渲染，包括：
- Markdown 渲染（markdown-it）
- 代码高亮（highlight.js）
- 数学公式（KaTeX）
- 引用来源展示
- 附件预览
- 操作按钮（复制、朗读、反馈）

### 4.2 Markdown 渲染

```jsx
import MarkdownIt from "markdown-it";
import hljs from "highlight.js";

const md = new MarkdownIt({
  highlight: function (str, lang) {
    if (lang && hljs.getLanguage(lang)) {
      return hljs.highlight(str, { language: lang }).value;
    }
    return '';
  },
});

function MessageContent({ content }) {
  const html = md.render(content);
  return <div dangerouslySetInnerHTML={{ __html: html }} />;
}
```

**安全注意**：使用 `dangerouslySetInnerHTML` 存在 XSS 风险。AnythingLLM 在后端使用 DOMPurify 净化，前端可考虑使用 `dompurify` 再次净化。

### 4.3 操作按钮

```jsx
function MessageActions({ message }) {
```

## 5. 聊天输入

### 5.1 功能

`ChatInput` 组件支持：
- 多行文本输入（Shift+Enter 换行，Enter 发送）
- 文件拖拽上传（react-dropzone）
- 粘贴图片（Clipboard API）
- 语音输入（react-speech-recognition）
- 附件预览与移除

### 5.2 语音输入

```jsx
import SpeechRecognition, { useSpeechRecognition } from "react-speech-recognition";

function VoiceInput({ onResult }) {
  const { transcript, listening, startListening, stopListening } = useSpeechRecognition();

  useEffect(() => {
    if (!listening && transcript) {
      onResult(transcript);
    }
  }, [listening, transcript]);

  return (
    <button
      onClick={listening ? stopListening : startListening}
      className={listening ? 'recording' : ''}
    >
      {listening ? '🔴 录音中...' : '🎤 语音输入'}
    </button>
  );
}
```

## 6. TTS 朗读

### 6.1 功能

AnythingLLM 支持多种 TTS 引擎：
- **Web Speech API**：浏览器原生 TTS（免费，质量一般）
- **Piper TTS**：本地高质量 TTS（@mintplex-labs/piper-tts-web）
- **ElevenLabs**：云端高质量 TTS（需 API Key）

### 6.2 自动朗读

```jsx
// TTSProvider 上下文
export function TTSProvider({ children }) {
  const [autoPlay, setAutoPlay] = useState(false);
  const [provider, setProvider] = useState("native");

  const speak = async (text) => {
    switch (provider) {
      case "native":
        const utterance = new SpeechSynthesisUtterance(text);
        speechSynthesis.speak(utterance);
        break;
      case "piper":
        await piperTTS.synthesize(text);
        break;
      case "elevenlabs":
        await elevenLabsTTS.synthesize(text);
        break;
    }
  };

  return (
    <TTSContext.Provider value={{ speak, autoPlay, setAutoPlay, provider, setProvider }}>
      {children}
    </TTSContext.Provider>
  );
}
```

## 7. 自动滚动

### 7.1 useAutoScroll Hook

```jsx
// frontend/src/hooks/useAutoScroll.js
export function useAutoScroll(dependencies) {
  const containerRef = useRef(null);
  const [isAtBottom, setIsAtBottom] = useState(true);

  useEffect(() => {
    if (isAtBottom && containerRef.current) {
      containerRef.current.scrollTop = containerRef.current.scrollHeight;
    }
  }, [dependencies]);

  const handleScroll = () => {
    const { scrollTop, scrollHeight, clientHeight } = containerRef.current;
    setIsAtBottom(scrollHeight - scrollTop - clientHeight < 50);
  };

  return { containerRef, handleScroll, isAtBottom };
}
```

**设计要点**：
- 仅在用户已滚动到底部时自动滚动
- 用户向上查看历史时不强制滚动
