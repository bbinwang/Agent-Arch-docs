**功能**：主索引方法，执行两遍扫描算法。

**参数**：
- `folder`: 要索引的文件夹路径

**核心算法（两遍扫描）**：

```
index_folder(folder):
    ┌─────────────────────────────────────────────────────────┐
    │ Pass 1: 解析所有文档（顺序）                              │
    │   for file in supported_files:                          │
    │     content = parse_file(file)                          │
    │     if is_error(content): skip                          │
    │     parsed_docs.append((file, relative_path, content))  │
    │                                                         │
    │ 并行元数据提取（ThreadPoolExecutor）                      │
    │   metadata_map = extract_metadata_batch(parsed_docs)    │
    ├─────────────────────────────────────────────────────────┤
    │ Pass 2: 分块 + 写入（顺序，DB 操作）                      │
    │   for (file, path, content) in parsed_docs:             │
    │     chunks = chunker.chunk_text(content)                │
    │     doc_record = create_document_record(...)            │
    │     storage.upsert_document(doc_record, chunks)         │
    ├─────────────────────────────────────────────────────────┤
    │ 后处理                                                   │
    │   mark_deleted_missing_documents()                      │
    │   generate_and_store_embeddings()                       │
    └─────────────────────────────────────────────────────────┘
```

**详细流程**：

```python
# 1. 验证和初始化
root = str(Path(folder).resolve())
if not os.path.exists(root) or not os.path.isdir(root):
    raise ValueError(f"No such directory: {root}")

# 2. Schema 解析（4 条路径）
effective_with_metadata = with_metadata or metadata_profile is not None
corpus_id = self.storage.get_or_create_corpus(root)
schema_def, selected_schema_name = self._resolve_schema(...)

# 3. Pass 1: 解析文档
parsed_docs: list[tuple[str, str, str]] = []
for file_path in self._iter_supported_files(root):
    content = parse_file(file_path)
    if self._is_parse_error(content):
        skipped_files += 1
        continue
    parsed_docs.append((file_path, relative_path, content))

# 4. 并行元数据提取
metadata_map = self._extract_metadata_batch(...)

# 5. Pass 2: 分块 + 写入
for file_path, relative_path, content in parsed_docs:
    chunks = self.chunker.chunk_text(content)
    metadata = metadata_map[relative_path]
    # ... 创建 DocumentRecord 和 ChunkRecord ...
    self.storage.upsert_document(doc_record, chunk_records)

# 6. 删除检测
deleted_files = self.storage.mark_deleted_missing_documents(...)

# 7. 嵌入生成
embeddings_written = self._generate_and_store_embeddings(...)
```

**时间复杂度**：
- Pass 1: O(n × parse)，n 为文件数
- 元数据提取: O(n × metadata / k)，k 为工作线程
- Pass 2: O(n × chunk)
- 总体: O(n × (parse + metadata + chunk))

**设计模式**：
- 管道-过滤器（Pipe-Filter）
- 两阶段提交（解析和写入分离）

#### _extract_metadata_batch()

```python
def _extract_metadata_batch(
    self,
    *,
    parsed_docs: list[tuple[str, str, str]],
    root_path: str,
    schema_def: dict[str, Any] | None,
    with_langextract: bool,
    langextract_profile: dict[str, Any] | None,
) -> dict[str, dict[str, Any]]:
    """Extract metadata for all documents in parallel using a thread pool."""

    def _extract_one(item: tuple[str, str, str]) -> tuple[str, dict[str, Any]]:
        file_path, relative_path, content = item
        metadata = extract_metadata(
            file_path=file_path,
            root_path=root_path,
            content=content,
            schema_def=schema_def,
            with_langextract=with_langextract,
            langextract_profile=langextract_profile,
        )
        return relative_path, metadata

    result: dict[str, dict[str, Any]] = {}
    if not parsed_docs:
        return result

    with ThreadPoolExecutor(max_workers=self._max_workers) as executor:
        for relative_path, metadata in executor.map(_extract_one, parsed_docs):
            result[relative_path] = metadata

    return result
```

**功能**：并行提取所有文档的元数据。

**核心逻辑**：
1. 定义内部函数 `_extract_one` 处理单个文档
2. 使用 `executor.map` 保持输入顺序
3. 收集结果到字典

**设计模式**：Map 模式（函数式并行映射）。

#### _generate_and_store_embeddings()

```python
def _generate_and_store_embeddings(
    self,
    *,
    corpus_id: str,
    all_chunk_records: list[ChunkRecord],
) -> int:
    """Embed chunk texts and store in the database. Returns count written."""
    if self.embedding_provider is None or not all_chunk_records:
        return 0

    texts = [cr.text for cr in all_chunk_records]
    embeddings = self.embedding_provider.embed_texts(texts)

    pairs: list[tuple[str, list[float]]] = [
        (cr.id, emb) for cr, emb in zip(all_chunk_records, embeddings)
    ]
    written = self.storage.store_chunk_embeddings(
        corpus_id=corpus_id,
        chunk_embeddings=pairs,
    )

    if isinstance(self.storage, DuckDBStorage):
        self.storage.create_hnsw_index(corpus_id=corpus_id)

    return written
```

**功能**：批量生成嵌入并存储，创建 HNSW 索引。

**核心逻辑**：
1. 检查 embedding_provider 是否存在
2. 提取所有 chunk 文本
3. 批量调用 `embed_texts`（内部按 batch_size 分批）
4. 存储 (chunk_id, embedding) 对
5. 如果是 DuckDB，创建 HNSW 索引

**设计模式**：模板方法（嵌入生成和存储分离）。

#### chunk_text()

```python
def chunk_text(self, text: str) -> list[TextChunk]:
    """
    Split text into chunks while preferring paragraph boundaries.
    """
    normalized = text.strip()
    if not normalized:
        return []

    chunks: list[TextChunk] = []
    start = 0
    position = 0
    total = len(normalized)

    while start < total:
        tentative_end = min(start + self.chunk_size, total)
        end = tentative_end

        if tentative_end < total:
            boundary = normalized.rfind("\n\n", start + (self.chunk_size // 2), tentative_end)
            if boundary != -1:
                end = boundary + 2

        chunk_text = normalized[start:end].strip()
        if chunk_text:
            chunks.append(
                TextChunk(
                    text=chunk_text,
                    position=position,
                    start_char=start,
                    end_char=end,
                )
            )
            position += 1

        if end >= total:
            break
        start = max(0, end - self.overlap)

    return chunks
```

**功能**：段落感知的分块算法。

**参数**：
- `text`: 要分块的文本

**返回值**：TextChunk 列表。

**算法伪代码**：

```
chunk_text(text):
    normalized = text.strip()
    start = 0
    position = 0
    
    while start < len(normalized):
        # 1. 计算试探性结束位置
        tentative_end = min(start + chunk_size, total)
        end = tentative_end
        
        # 2. 如果不是最后一块，寻找段落边界
        if tentative_end < total:
            # 在 [start + chunk_size/2, tentative_end] 区间查找双换行
            boundary = rfind("\n\n", start + chunk_size/2, tentative_end)
            if boundary != -1:
                end = boundary + 2  # 包含换行符
        
        # 3. 创建 chunk
        chunk_text = normalized[start:end].strip()
        if chunk_text:
            chunks.append(TextChunk(chunk_text, position, start, end))
            position += 1
        
        # 4. 移动 start 位置（带重叠）
        if end >= total: break
        start = max(0, end - overlap)
    
    return chunks
```

**算法特点**：
1. **段落感知**：在 chunk_size/2 到 tentative_end 之间查找段落边界（`\n\n`）
2. **重叠策略**：下一块的起始位置回退 overlap 个字符
3. **边界处理**：最后一块不查找边界

**复杂度分析**：
- 时间复杂度：O(n)，n 为文本长度（每个字符最多被访问常数次）
- 空间复杂度：O(n)，存储所有 chunk

**示例**：

```
输入: "Paragraph 1...\n\nParagraph 2...\n\nParagraph 3..."
chunk_size=20, overlap=5

Chunk 0: "Paragraph 1..." (position=0, start=0, end=14)
Chunk 1: "..\n\nParagraph 2..." (position=1, start=9, end=30)  # 重叠 5 字符
Chunk 2: "..\n\nParagraph 3..." (position=2, start=25, end=45)
```

**设计模式**：
- 滑动窗口
- 贪心算法（尽可能在段落边界切分）

**潜在问题**：
- 如果文本没有段落分隔（如连续长文本），会硬切在 chunk_size 处
- 重叠区域可能切断单词或句子

```python
def _search_parallel(
    self,
    *,
    corpus_id: str,
    query: str,
    metadata_filters: list[MetadataFilter],
    semantic_limit: int,
    metadata_limit: int,
```

```python
def _semantic_query(
    self,
    *,
    corpus_id: str,
    query: str,
    limit: int,
) -> list[dict[str, Any]]:
    scoped_storage, cleanup = self._acquire_query_storage()
    try:
```

### 6.6 _parse_condition()

```python
def _parse_condition(condition: str, *, allowed_fields: set[str] | None) -> MetadataFilter:
    text = condition.strip()
    if not text:
        raise MetadataFilterParseError("Empty filter condition.")

    # 1. 尝试匹配 IN 操作符
    in_match = re.match(r"^\s*([A-Za-z_][A-Za-z0-9_]*)\s+in\s+(.+)\s*$", text, flags=re.IGNORECASE)
    if in_match:
        field = in_match.group(1)
        _validate_field(field, allowed_fields=allowed_fields)
        values = _parse_list_value(in_match.group(2))
        if not values:
            raise MetadataFilterParseError(f"`in` filter has no values: {text!r}")
        return MetadataFilter(field=field, operator="in", value=values)

    # 2. 尝试匹配比较操作符
    op_match = re.match(r"^\s*([A-Za-z_][A-Za-z0-9_]*)\s*(<=|>=|!=|=|<|>|~|:)\s*(.+)\s*$", text)
    if not op_match:
        raise MetadataFilterParseError(f"Invalid filter syntax: {text!r}")

    field = op_match.group(1)
    operator_symbol = op_match.group(2)
    raw_value = op_match.group(3)
    _validate_field(field, allowed_fields=allowed_fields)
    value = _parse_scalar_value(raw_value)

    operator_map: dict[str, FilterOperator] = {
        "=": "eq", ":": "eq", "!=": "ne",
        ">": "gt", ">=": "gte", "<": "lt", "<=": "lte", "~": "contains",
    }
    operator = operator_map[operator_symbol]

    # 3. 验证数值操作符的值类型
    if operator in {"gt", "gte", "lt", "lte"} and not isinstance(value, (int, float)):
        raise MetadataFilterParseError(
            f"Operator `{operator_symbol}` requires a numeric value: {text!r}"
        )

    return MetadataFilter(field=field, operator=operator, value=value)
```

**功能**：解析单个条件。

**解析优先级**：
1. IN 操作符（需要特殊处理列表值）
2. 比较操作符（<=, >=, !=, =, <, >, ~, :）

**操作符映射**：

| 符号 | 操作符 |
|------|--------|
| `=` | eq |
| `:` | eq |
| `!=` | ne |
| `>` | gt |
| `>=` | gte |
| `<` | lt |
| `<=` | lte |
| `~` | contains |

### 6.8 _split_conditions()

```python
def _split_conditions(raw: str) -> list[str]:
    parts: list[str] = []
    current: list[str] = []
    quote: str | None = None
    paren_depth = 0
    bracket_depth = 0
    i = 0
    while i < len(raw):
        ch = raw[i]

        # 1. 引号内内容原样保留
        if quote is not None:
            current.append(ch)
            if ch == quote:
                quote = None
            i += 1
            continue

        # 2. 进入引号
        if ch in {"'", '"'}:
            quote = ch
            current.append(ch)
            i += 1
            continue

        # 3. 括号深度跟踪
        if ch == "(":
            paren_depth += 1
            current.append(ch)
            i += 1
            continue
        if ch == ")":
            paren_depth = max(paren_depth - 1, 0)
            current.append(ch)
            i += 1
            continue

        # 4. 方括号深度跟踪
        if ch == "[":
            bracket_depth += 1
            current.append(ch)
            i += 1
            continue
        if ch == "]":
            bracket_depth = max(bracket_depth - 1, 0)
            current.append(ch)
            i += 1
            continue

        # 5. 逗号分隔（仅在顶层）
        if paren_depth == 0 and bracket_depth == 0 and ch == ",":
            _flush_part(parts, current)
            i += 1
            continue

        # 6. "and" 分隔（仅在顶层）
        if (
            paren_depth == 0
            and bracket_depth == 0
            and raw[i : i + 3].lower() == "and"
            and (i == 0 or raw[i - 1].isspace())
            and (i + 3 == len(raw) or raw[i + 3].isspace())
        ):
            _flush_part(parts, current)
            i += 3
            continue

        current.append(ch)
        i += 1

    _flush_part(parts, current)
    return parts
```

**功能**：将多条件字符串拆分为单个条件。

**核心逻辑**：
1. 跟踪引号状态（单引号/双引号）
2. 跟踪括号深度（`()` 和 `[]`）
3. 仅在顶层（深度为 0）识别分隔符
4. 支持逗号和 `and` 作为分隔符

**状态机**：

```
字符 → 状态转换：
- 引号字符 → 进入/退出引号状态
- ( → paren_depth++
- ) → paren_depth--
- [ → bracket_depth++
- ] → bracket_depth--
- , (顶层) → 分隔
- "and" (顶层) → 分隔
```

**时间复杂度**：O(n)，单次遍历。

```python
@dataclass(frozen=True)
class RankedDocument:
    """Merged retrieval candidate for a document."""
    doc_id: str
    relative_path: str
    absolute_path: str
    position: int | None
    text: str
    semantic_score: float
    metadata_score: int

    @property
    def combined_score(self) -> float:
        return float(self.semantic_score * 100 + self.metadata_score * 10)

    @property
    def matched_by(self) -> str:
        if self.semantic_score > 0 and self.metadata_score > 0:
            return "semantic+metadata"
        if self.semantic_score > 0:
            return "semantic"
        return "metadata"
```

**功能**：不可变数据类，表示合并后的候选文档。

**combined_score 计算公式**：

```
combined_score = semantic_score × 100 + metadata_score × 10
```

**设计意图**：
- 语义分数主导排序（权重 100）
- 元数据分数用于打破平局和提升纯元数据匹配（权重 10）

**示例**：

| semantic_score | metadata_score | combined_score |
|----------------|----------------|----------------|
| 0.85 | 3 | 85 + 30 = 115 |
| 0.90 | 0 | 90 + 0 = 90 |
| 0.00 | 5 | 0 + 50 = 50 |

**matched_by 属性**：
- `semantic+metadata`：双路径匹配
- `semantic`：仅语义匹配
- `metadata`：仅元数据匹配

### 7.2 rank_documents()

```python
def rank_documents(
    documents: list[RankedDocument], *, limit: int
) -> list[RankedDocument]:
    """Sort merged retrieval results and apply limit."""
    ordered = sorted(
        documents,
        key=lambda doc: (
            -doc.combined_score,
            -doc.semantic_score,
            -doc.metadata_score,
            doc.position if doc.position is not None else 10**9,
            doc.relative_path,
        ),
    )
    return ordered[: max(limit, 1)]
```

**功能**：排序并限制结果数量。

**排序键（优先级从高到低）**：
1. `-combined_score`：综合分数降序
2. `-semantic_score`：语义分数降序
3. `-metadata_score`：元数据分数降序
4. `position`：位置升序（None 视为 10^9，排到最后）
5. `relative_path`：路径升序（确保确定性排序）

**时间复杂度**：O(n log n)，n 为文档数。

**设计模式**：
- 策略模式（多键排序）
- 确定性排序（避免不确定顺序）
