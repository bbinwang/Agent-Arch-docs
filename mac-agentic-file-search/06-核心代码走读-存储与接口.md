### 2.1 _stable_id()

```python
def _stable_id(prefix: str, value: str) -> str:
    digest = hashlib.sha1(value.encode("utf-8")).hexdigest()
    return f"{prefix}_{digest}"
```

**功能**：生成基于 SHA1 的稳定 ID。

**参数**：
- `prefix`: ID 前缀（如 "corpus", "doc", "chunk"）
- `value`: 要哈希的值

**返回值**：`"{prefix}_{sha1_hex}"` 格式的 ID

**示例**：
- `_stable_id("corpus", "/path/to/folder")` → `"corpus_a1b2c3d4..."`
- `_stable_id("doc", "corpus_id:relative_path")` → `"doc_e5f6g7h8..."`

**设计模式**：确定性 ID（相同输入始终产生相同输出）。

### 2.2 _query_terms()

```python
def _query_terms(query: str, max_terms: int = 8) -> list[str]:
    terms = re.findall(r"[a-zA-Z0-9_]{3,}", query.lower())
    unique_terms: list[str] = []
    for term in terms:
        if term not in unique_terms:
            unique_terms.append(term)
        if len(unique_terms) >= max_terms:
            break
    if unique_terms:
        return unique_terms
    fallback = query.strip().lower()
    return [fallback] if fallback else []
```

**功能**：从查询文本中提取搜索词。

**参数**：
- `query`: 查询文本
- `max_terms`: 最大词数（默认 8）

**核心逻辑**：
1. 使用正则提取至少 3 个字符的字母数字词
2. 小写化
3. 去重（保持顺序）
4. 限制数量
5. 如果没有提取到词，使用整个查询作为回退

**示例**：
- `"purchase price agreement"` → `["purchase", "price", "agreement"]`
- `"the"` → `["the"]`（回退）

#### upsert_document()

```python
def upsert_document(
    self, document: DocumentRecord, chunks: list[ChunkRecord]
) -> None:
    # 1. 级联删除旧 embedding
    self._conn.execute(
        """
        DELETE FROM chunk_embeddings
        WHERE chunk_id IN (SELECT id FROM chunks WHERE doc_id = ?)
        """,
        [document.id],
    )
    # 2. 删除旧 chunks
    self._conn.execute("DELETE FROM chunks WHERE doc_id = ?", [document.id])

    # 3. 插入/更新文档
    self._conn.execute(
        """
        INSERT INTO documents (...)
        VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, FALSE)
        ON CONFLICT(id) DO UPDATE SET
            corpus_id = excluded.corpus_id,
            ...,
            last_indexed_at = now(),
            is_deleted = FALSE
        """,
        [document.id, document.corpus_id, ...],
    )

    # 4. 批量插入 chunks
    if chunks:
        self._conn.executemany(
            "INSERT INTO chunks (id, doc_id, text, position, start_char, end_char) VALUES (?, ?, ?, ?, ?)",
            [(chunk.id, chunk.doc_id, ...) for chunk in chunks],
        )
```

**功能**：插入或更新文档及其 chunks。

**核心逻辑**：
1. 级联删除旧 embeddings
2. 删除旧 chunks
3. UPSERT 文档（INSERT ON CONFLICT DO UPDATE）
4. 批量插入新 chunks

**设计模式**：
- 级联删除
- 批量插入（executemany）

#### mark_deleted_missing_documents()

```python
def mark_deleted_missing_documents(
    self, *, corpus_id: str, active_relative_paths: set[str],
) -> int:
    if not active_relative_paths:
        # 全部标记为删除
        self._conn.execute(
            "UPDATE documents SET is_deleted = TRUE WHERE corpus_id = ? AND is_deleted = FALSE",
            [corpus_id],
        )
    else:
        # 标记不在 active_paths 中的文档
        placeholders = ", ".join(["?"] * len(active_relative_paths))
        params: list[Any] = [corpus_id]
        params.extend(sorted(active_relative_paths))
        self._conn.execute(
            f"""
            UPDATE documents SET is_deleted = TRUE
            WHERE corpus_id = ? AND is_deleted = FALSE
              AND relative_path NOT IN ({placeholders})
            """,
            params,
        )

    # 返回删除总数
    row = self._conn.execute(
        "SELECT COUNT(*) FROM documents WHERE corpus_id = ? AND is_deleted = TRUE", [corpus_id],
    ).fetchone()
    return int(row[0]) if row else 0
```

**功能**：软删除不在活跃路径集合中的文档。

**返回值**：标记为删除的文档总数。

**设计模式**：软删除（Soft Delete）。

**功能**：关键词搜索 chunks。

**评分公式**：

```
score = Σ (CASE WHEN text LIKE '%term%' THEN 1 ELSE 0 END)
```

即：匹配的 term 数量（每个 term 匹配得 1 分，不重复计数）。

**SQL 生成示例**：

对于查询 `"purchase price"`，生成：
```sql
SELECT * FROM (
    SELECT
        d.id AS doc_id,
        d.relative_path,
        d.absolute_path,
        c.position,
        c.text,
        (CASE WHEN lower(c.text) LIKE '%purchase%' THEN 1 ELSE 0 END
         + CASE WHEN lower(c.text) LIKE '%price%' THEN 1 ELSE 0 END) AS score
    FROM chunks c
    JOIN documents d ON d.id = c.doc_id
    WHERE d.corpus_id = ? AND d.is_deleted = FALSE
) ranked
WHERE score > 0
ORDER BY score DESC, relative_path ASC, position ASC
LIMIT ?
```

**设计模式**：
- 动态 SQL 生成
- 简单词频评分

**潜在问题**：
- LIKE 查询在大数据量时性能差
- 评分只考虑是否匹配，不考虑词频或位置

#### _metadata_clause()

```python
@staticmethod
def _metadata_clause(
    self, *, field: str, operator: str, value: Any,
) -> tuple[str, list[Any]]:
    json_expr = "json_extract_string(d.metadata_json, ?)"
    json_path = f"$.{field}"

    if operator in {"eq", "ne"}:
        comparator = "=" if operator == "eq" else "<>"
        if isinstance(value, bool):
            return (f"lower(coalesce({json_expr}, '')) {comparator} ?", [json_path, "true" if value else "false"])
        if isinstance(value, (int, float)):
            return (f"try_cast({json_expr} AS DOUBLE) {comparator} ?", [json_path, float(value)])
        return (f"lower(coalesce({json_expr}, '')) {comparator} lower(?)", [json_path, str(value)])

    if operator in {"gt", "gte", "lt", "lte"}:
        if not isinstance(value, (int, float)):
            raise ValueError(...)
        comparator_map = {"gt": ">", "gte": ">=", "lt": "<", "lte": "<="}
        comparator = comparator_map[operator]
        return (f"try_cast({json_expr} AS DOUBLE) {comparator} ?", [json_path, float(value)])

    if operator == "contains":
        return (f"lower(coalesce({json_expr}, '')) LIKE '%' || lower(?) || '%'", [json_path, str(value)])

    if operator == "in":
        if not isinstance(value, list) or not value:
            raise ValueError(...)
        if all(isinstance(item, bool) for item in value):
            placeholders = ", ".join(["?"] * len(value))
            return (f"lower(coalesce({json_expr}, '')) IN ({placeholders})", [json_path, *["true" if bool(item) else "false" for item in value]])
        if all(isinstance(item, (int, float)) and not isinstance(item, bool) for item in value):
            placeholders = ", ".join(["?"] * len(value))
            return (f"try_cast({json_expr} AS DOUBLE) IN ({placeholders})", [json_path, *[float(item) for item in value]])
        placeholders = ", ".join(["?"] * len(value))
        return (f"lower(coalesce({json_expr}, '')) IN ({placeholders})", [json_path, *[str(item).lower() for item in value]])

    raise ValueError(f"Unsupported metadata operator: {operator!r}")
```

**功能**：为各种操作符生成 SQL 子句。

**支持的类型处理**：

| 操作符 | 值类型 | SQL 生成 |
|--------|--------|----------|
| eq/ne | bool | `lower(...) = 'true'/'false'` |
| eq/ne | number | `try_cast(... AS DOUBLE) = ?` |
| eq/ne | string | `lower(...) = lower(?)` |
| gt/gte/lt/lte | number | `try_cast(... AS DOUBLE) > ?` |
| contains | string | `lower(...) LIKE '%' \|\| lower(?) \|\| '%'` |
| in | bool list | `lower(...) IN ('true', 'false', ...)` |
| in | number list | `try_cast(... AS DOUBLE) IN (1.0, 2.0, ...)` |
| in | string list | `lower(...) IN ('a', 'b', ...)` |

**核心函数**：
- `json_extract_string(json, path)`：从 JSON 字符串提取值
- `try_cast(expr AS DOUBLE)`：安全类型转换
- `coalesce(expr, '')`：空值处理

#### embed_texts()

```python
def embed_texts(
    self, texts: list[str], *, task_type: str = "RETRIEVAL_DOCUMENT",
) -> list[list[float]]:
    """Embed a list of texts in batches.

    Returns a list of embedding vectors in the same order as *texts*.
    """
    all_embeddings: list[list[float]] = []
    for start in range(0, len(texts), self.batch_size):
        batch = texts[start : start + self.batch_size]
        result = self._client.models.embed_content(
            model=self.model,
            contents=batch,
            config={
                "task_type": task_type,
                "output_dimensionality": self.dim,
            },
        )
        for emb in result.embeddings:
            all_embeddings.append(list(emb.values))
    return all_embeddings
```

**功能**：批量嵌入文本列表。

**参数**：
- `texts`: 要嵌入的文本列表
- `task_type`: 任务类型（默认 RETRIEVAL_DOCUMENT）

**核心逻辑**：
1. 按 batch_size 分批
2. 调用 embed_content API
3. 收集结果

**task_type 说明**：
- `RETRIEVAL_DOCUMENT`：文档嵌入（用于索引）
- `RETRIEVAL_QUERY`：查询嵌入（用于搜索）

**时间复杂度**：O(n/batch_size) 次 API 调用

### 6.2 resolve_db_path()

```python
def resolve_db_path(override_path: str | None = None) -> str:
    """
    Resolve the DuckDB path from CLI override, env var, or default.

    Precedence:
    1) explicit override_path
    2) FS_EXPLORER_DB_PATH
    3) default path
    """
    raw_path = override_path or os.getenv(ENV_DB_PATH) or DEFAULT_DB_PATH
    resolved = Path(raw_path).expanduser().resolve()
    resolved.parent.mkdir(parents=True, exist_ok=True)
    return str(resolved)
```

**功能**：解析 DuckDB 路径，支持三级优先级。

**参数**：
- `override_path`: CLI 显式指定的路径

**优先级**：
1. override_path（最高）
2. FS_EXPLORER_DB_PATH 环境变量
3. ~/.fs_explorer/index.duckdb（默认）

**核心逻辑**：

## 潜在问题和改进建议

1. **锁字典泄漏**：`_corpus_locks` 无限增长，建议添加清理机制或使用 WeakValueDictionary
2. **DuckDB 连接管理**：频繁创建/关闭连接有开销，建议使用连接池
3. **LIKE 查询性能**：search_chunks 的 LIKE 查询在大数据量时慢，建议添加 FTS 索引
4. **错误处理粒度**：server.py 捕获所有 Exception，建议分类处理
5. **WebSocket 超时**：无超时设置，长时间运行可能占用连接
6. **嵌入批量大小**：硬编码 50，建议根据 API 限制动态调整
7. **SQL 注入风险**：`_metadata_clause` 使用 f-string 拼接字段名，虽然字段名来自 schema 验证，但建议参数化
